# 🌐  Yearly Census Dashboard

A decentralized census dashboard for a Network State — where citizens across the world can verify their identity using Zero Knowledge Proofs and get permanently recorded on the blockchain.

## 🚀 Live Demo
Run locally at `localhost:3000`

## 📌 What This Project Does
A Network State is an online society whose members live across the world. Like any real country needs a census, this online society needs a way to count and verify its citizens — without invading their privacy.

Citizens can:
- Prove their GitHub identity using **Zero Knowledge Proofs**
- Get permanently recorded on **Polygon Amoy blockchain**
- View live census metrics on the dashboard

## 🔧 Setup & Installation

### Prerequisites
- Node.js installed
- MetaMask browser extension
- Polygon Amoy testnet configured in MetaMask

### Installation
```bash
# Clone the repo
git clone https://github.com/Eisha373/Yearly_census_Dashboard021.git

# Go to frontend folder
cd Yearly_census_Dashboard021/frontend

# Install dependencies
npm install

# Run the app
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🔑 Key Concepts
- **Network State:** A society organized online rather than geographically
- **Zero Knowledge Proof:** Proving a fact without revealing the underlying data
- **Smart Contract:** Self-executing code on blockchain — no human intermediary
- **Reclaim Protocol:** Infrastructure for generating ZK proofs from real-world data
